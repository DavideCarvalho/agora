# Overview

| Engine | Data model | History | Best for |
|---|---|---|---|
| `yjs` | Shared types + rich text | Snapshots | Text, Tiptap, Excalidraw/tldraw scenes |
| `automerge` | JSON-like document | Native change graph | Structured documents, form-like data |
| `partykit`/`partyserver` | Same as Yjs (edge) | Snapshots | Global latency, separate origin |

Route per document with `engineFor` or `documents` — see [Documents](/docs/collaboration/concepts/documents).

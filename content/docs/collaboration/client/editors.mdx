# Editors

`useCollabEditor` couples an editor adapter to a document; the server's engine decides the transport underneath.

```tsx
const { state, update, status, peers } = useCollabEditor({
  docName: 'lousas/1',
  editorId: 'excalidraw',
  adapter: createExcalidrawAdapter(),
})
```

| Adapter | Surface |
|---|---|
| `createExcalidrawAdapter()` | Scene (`elements`, `appState`) |
| `createTldrawAdapter()` | tldraw snapshot (`records` + schema) |
| `createTextAdapter()` | Plain text |

# Commands

- `collaboration:init` — base directories, migrations, PartyKit worker
- `make:collab-document <name>` — shared types in `app/collaboration/documents/`

```sh
node ace make:collab-document researches/writing
# creates app/collaboration/documents/writing_types.ts
```

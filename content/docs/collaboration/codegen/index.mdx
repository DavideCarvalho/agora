# Codegen

AdonisJS v7 generates code from your application into `.adonisjs/`. The collaboration package plugs in so documents are typed in one place and reused everywhere.

## Commands

- `collaboration:init` — base directories, migrations, PartyKit worker
- `make:collab-document <name>` — shared types in `app/collaboration/documents/`

# Collaboration

Pacote do ecossistema Agora para edição colaborativa (CRDT) em AdonisJS. Documentos identificados por nome (`researches/42/writing`), engine por documento, version control unificado, comentários ancorados e hooks React no client.

## Features

- **Engines CRDT**: `yjs` (Hocuspocus embutido), `automerge`, `partykit`/`partyserver` (edge)
- **Presença server-side** (Redis, cross-instance) + awareness client-side
- **Version control** unificado (snapshots Yjs / heads Automerge)
- **Comentários ancorados** por espaço (`text-range`, `canvas-object`, `timestamp`)
- **Rotas REST builtin** auto-registradas (token, comments, versions) — tipáveis pelo Tuyau
- **Codegen ace**: `collaboration:init`, `make:collab-document`, registry tipado em `.adonisjs/`
- **Client React**: `useCollabDoc`, `useCollabEditor` (adapters Excalidraw/tldraw/text), `useAutomergeDoc`

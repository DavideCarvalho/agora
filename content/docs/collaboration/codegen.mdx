# Codegen

## Comandos

- `collaboration:init` — diretórios base, migrations, worker PartyKit
- `make:collab-document <name>` — tipos compartilhados em `app/collaboration/documents/`

## Registry tipado

Hook `init` do Assembler gera `.adonisjs/collaboration/documents.ts`:

```ts
import type { CollabDocumentName } from '.adonisjs/collaboration/documents.js'
function open(name: CollabDocumentName) { /* autocomplete + exhaustiveness */ }
```

Atualize com `node ace codegen` (ou dev server/build).

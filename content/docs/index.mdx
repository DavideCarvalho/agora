# Agora

**Agora** is a family of production-grade libraries for AdonisJS — a Greek gathering place for your
app's cross-cutting concerns. Each library ships on its own, but they compose: they share context,
emit to one diagnostics bus, and surface in one observability console.

New here? **[Getting started](/docs/getting-started)** installs a first library and connects your coding
agent to it.

## The libraries

- **[Context](/docs/context)** — ambient request/tenant/correlation context across HTTP, queue, durable and ace.
- **[Diagnostics](/docs/diagnostics)** — a diagnostics bus over `node:diagnostics_channel` with an OpenTelemetry auto-bridge.
- **[Resilience](/docs/resilience)** — timeout / retry / circuit-breaker / failover policies, with a distributed breaker store.
- **[Durable](/docs/durable)** — durable, resumable, cross-process workflows.
- **[Telescope](/docs/telescope)** — a Telescope-style observability console with an extensible dashboard.
- **[Authz](/docs/authz)** — DB-backed roles & permissions that feed AdonisJS Bouncer, with wildcards, tenancy and ace commands.
- **[Collaboration](/docs/collaboration)** — collaborative editing (CRDT) for AdonisJS, with Yjs/Automerge/edge engines, Redis presence, version control, anchored comments and React client hooks.
- **[Media](/docs/media)** — owner collections, image conversions, and column attachments on top of `@adonisjs/drive`.
- **[Filter](/docs/filter)** — a typed query-param filter language for Lucid, with defineFilter classes, offset & cursor pagination, relations via whereHas, full-text and vector-similarity search, and a typed client with codegen.
- **[Payments](/docs/payments)** — multi-gateway payments and Cashier-style billing, with 18 gateways behind one driver contract, invoice emission and method-based routing.
- **[Flags](/docs/flags)** — feature flags and A/B experiments with real statistics (SRM, CUPED, sequential tests), targeting in your database, Parquet/DuckDB and ClickHouse analytics, a central flags server for many apps, and OpenFeature/OFREP.
- **[Agent](/docs/agent)** — a governed, durable-ready AI agent: streaming chat, tool-calling, HITL approvals, quota/cost accounting and multi-agent delegation.
- **[AuthKit](/docs/authkit)** — a full OIDC/OAuth2 Authorization Server (IdP) + OIDC client + React ergonomics: MFA, passwordless, device flow, DPoP and more.
- **[CMS](/docs/cms)** — a config-first CMS: collections, globals, drafts, i18n and a schema-driven admin panel.
- **[Sail](/docs/sail)** — Docker-powered local dev services, isolated per git worktree.

## How they fit together

Everything is wired through small `Symbol.for('@agora/<lib>:<name>')` capability slots, so a library
lights up its neighbours **when present** and no-ops when absent — no hard dependencies between repos.
Install only what you need.

Cross-cutting shapes are shared the same way — matched structurally, never imported. See
**[Conventions](/docs/conventions)** for the ones that hold ecosystem-wide, starting with pagination.

## Your coding agent sees your app: `/mcp/agora`

With `@adonis-agora/agent` installed and its `mcp_provider` registered, your app serves one MCP
endpoint, `/mcp/agora`, where every installed library that has a console registers read tools:
durable runs, telescope entries, payments, agent spend and more. Connect Claude Code once:

```sh
claude mcp add --transport http agora http://localhost:3333/mcp/agora
```

Then ask it "why did run 42 fail?". Each lib's tools follow that lib's console `authorize`. See
[dev tools over MCP](/docs/agent/dev-tools).

## The consoles

The libraries with a web console share one look, so they feel like one product:

- **One shell.** The same sidebar, cards, tables and light/dark themes everywhere. Each console keeps
  one accent colour of its own, so you always know which one you are in.
- **A console switcher.** The brand at the top of the sidebar lists the other consoles the signed-in
  viewer may open. Each console decides with its own `authorize`.
- **⌘K search** (`Ctrl-K`) finds things in the console you are in and in the others: runs, entries,
  payments, users.
- **Who is signed in.** The sidebar footer shows the signed-in user and a sign-out button. With
  AuthKit installed, sign-out ends the AuthKit session in every console.

## MCP clients sign in by themselves

With AuthKit in the app, Claude Code, Claude, ChatGPT, VS Code and Cursor sign in to your MCP
endpoints with your users' own accounts. It turns on as soon as an MCP endpoint is registered, so
`/mcp/agora` needs no setup: the client opens your login in the browser and connects. See
[MCP clients](/docs/authkit/mcp-clients).

## Content: the CMS

[`@adonis-agora/cms`](/docs/cms) is a config-first CMS. Declare collections and globals in
`config/cms.ts`, and the tables, the admin panel, the REST and local APIs and the types follow. It
uses the same list format as the other libraries (see [Conventions](/docs/conventions)) and
exposes its content over MCP. The CMS is still on 0.x and installs from npm's `latest` tag. Start
with [using the CMS in an app](/docs/cms/using).

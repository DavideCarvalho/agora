---
title: Roadmap
description: Where the payments library is headed — drivers hardening, more invoice providers, dashboard and usage-based billing.
---

- **BR drivers hardening** — Asaas native NFS-e via the `invoice` option, Woovi Pix
  Automático journey 3 (pay-on-approval), AbacatePay transparent checkout
- **More invoice providers** — Tecnospeed, eNotas, PlugNotas adapters (today you can
  [write your own](./custom-providers) with the exported building blocks)
- **Webhook business logic** — the three options (folder, `billing.handlers`, events) are
  shipped; next: an out-of-the-box `@OnDiagnostic` durable trigger example once the
  durable event-trigger release lands
- **Commands** — `payments:sync` reconciliation polish, `payments:webhook` auto-create
  where the gateway API allows
- **Dashboard** — billing overview UI (Agora dashboard pattern)
- **Usage-based billing** — metered subscriptions
- **Splits & subaccounts** — Asaas split, Woovi subaccounts

**`@adonis-agora/payments`** brings multi-gateway payments and Cashier-style billing to
AdonisJS, built for the Brazilian market. One contract — `charge`, `refund`,
`createSubscription`, `parseWebhook` — normalized across **Stripe**, **AbacatePay**,
**Asaas** and **Woovi** (Pix Automático), so your services talk to one interface instead of
four SDKs. A charge can pay via Pix through Woovi and emit the fiscal invoice (NFe/NFSe)
through a completely different provider, in a single call.

<Callout type="info" title="The one rule">
A payment is **confirmed only by the webhook**. A `charge()` returns a `PENDING` record —
the money hasn't moved until the gateway calls your endpoint. The processor's idempotency
ledger and durable dispatch are what make "trust only the webhook" safe: forged callbacks
are rejected, redeliveries are no-ops, and a half-processed confirmation survives restarts.
See [Webhooks](/docs/payments/webhooks).
</Callout>

## The problem it solves

Payment integrations are usually a mess of gateway SDKs, hand-rolled status mirrors, and
webhook controllers that duplicate each other. `@adonis-agora/payments` collapses that into
four guarantees:

- **One driver contract, four gateways.** Every gateway normalizes onto the same
  `PaymentsDriver`. Adding a gateway is a config entry, not a code change — and a driver
  declares which methods it supports, so routing a card to a Pix-only gateway fails at the
  manager, not at the gateway.
- **Money moves only on confirmation.** The idempotent webhook processor (a gateway-event
  ledger written *before* any work runs) makes redeliveries no-ops. Your business logic —
  grant credits, activate a subscription — runs at the right moment, exactly once.
- **Billing mirrors the gateway.** Subscriptions, payments and trials sync into Lucid
  tables automatically, Cashier-style, with billable mixins on your models.
- **Fiscal notes are a separate concern.** Pay through one provider, emit the NFe/NFSe
  through another — the `invoice` option on the charge call joins them.

## Quickstart

The minimal loop — install, configure a gateway, run the migrations, charge — with one
provider and no invoice provider:

<Steps>
<Step>

Install and configure:

```bash
node ace add @adonis-agora/payments
```

This registers the `payments_provider` in `adonisrc.ts`, publishes `config/payments.ts`,
the billing migrations, and the ace commands.
</Step>

<Step>

Set a gateway secret and make your first charge:

```ini title=".env"
ASAAS_API_KEY=your-asaas-api-key
```

```ts title="config/payments.ts"
import env from '#start/env'
import { defineConfig, payments } from '@adonis-agora/payments'

export default defineConfig({
  default: 'asaas',
  providers: {
    asaas: payments.asaas({ apiKey: env.get('ASAAS_API_KEY') }),
  },
  methods: {
    pix: 'asaas',
    credit_card: 'asaas',
  },
})
```

```ts title="app/services/checkout_service.ts"
import { getPayments } from '@adonis-agora/payments/services/main'

const customer = await getPayments().driver('pix').createCustomer({
  name: 'Jane Doe',
  email: 'jane@example.com',
  taxId: '123.456.789-00',
})

// charge via Pix — the customer scans the QR, then the webhook confirms
const payment = await getPayments().driver('pix').charge({
  customerId: customer.id,
  amount: 1990, // R$ 19,90 — integer cents, never floats
})
```
</Step>

<Step>

Register the webhook and react to confirmations:

```sh
node ace payments:webhook   # prints the URL + event list per provider
node ace make:webhook-handler payment.succeeded
```

```ts title="app/payment_handlers/payment_succeeded.ts"
@inject()
export default class PaymentSucceededHandler {
  static readonly eventType = 'payment.succeeded'
  async handle(event: WebhookEvent): Promise<void> {
    // dispatch a durable workflow — durable owns retry + exactly-once
  }
}
```
</Step>
</Steps>

## The happy path, end to end

```text
your app ──charge()──▶ gateway (PENDING)
   ▲                        │
   │  webhook (paid)        │
   └──parseWebhook──────────┘
       │
       ├─ validate signature  (forged callbacks rejected)
       ├─ ledger the event    (redeliveries are no-ops)
       ├─ sync billing tables (billing_payments/subscriptions)
       ├─ run your handler    (grant credits / activate)
       └─ publish diagnostics (agora:payments:payment.succeeded)
```
